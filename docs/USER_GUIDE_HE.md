# ARAD Bridge — מדריך התקנה למשתמש

התוסף מחבר את הדפדפן שלך למערכות ARAD ומגדל: פתיחת מסמכים בפריוריטי, שליחת
וואטסאפ, ייבוא לוז מ-MS Project, OneDrive, ותמלול ישיבות **במחשב שלך**.

> **חשוב:** רק המודולים שהארגון שלך רכש נטענים ופועלים. הרשימה מגיעה אוטומטית
> ממסד הנתונים של ARAD אחרי ההתקנה.

---

## 1. התקנת התוסף בדפדפן (חובה)

זה כל מה שצריך לרוב השימושים.

1. **הורד את הקובץ** — מתוך מגדל: `הגדרות אישיות` ← הכרטיס "תוסף ARAD Bridge
   לדפדפן" ← כפתור ההורדה. (או מ-[הגרסה האחרונה בגיטהאב](https://github.com/liorgab/arad-bridge/releases/latest).)
2. **חלץ לתיקייה קבועה** — למשל `C:\ARAD-Bridge`. כרום טוען את התוסף **מהתיקייה
   הזו**, ומחיקתה מסירה אותו. אל תחלץ לתיקיית ההורדות.
3. פתח בכרום את `chrome://extensions`
4. הפעל **Developer mode** (מתג בפינה העליונה)
5. לחץ **Load unpacked** ובחר את התיקייה שחילצת — זו שיש בה `manifest.json`
6. חזור למגדל והקש `Ctrl+Shift+R`. הכרטיס יציג שהתוסף מותקן.

**עדכון לגרסה חדשה:** חלץ את ה-ZIP החדש **לאותה תיקייה** (דרוס), ואז
`chrome://extensions` ← כפתור הרענון על כרטיס התוסף.

---

## 2. Daemon — רק למי שצריך וואטסאפ המוני או תמלול

חלק מהמודולים עובדים מול תוכנית קטנה שרצה במחשב (`localhost:8766`).
בלעדיה שאר המודולים עובדים כרגיל.

```powershell
powershell -ExecutionPolicy Bypass -File installer\install_daemon.ps1
```

הסקריפט מתקין את ה-Daemon, יוצר קיצור דרך בשולחן העבודה ומפעיל אותו אוטומטית
בכניסה ל-Windows. דורש Python 3.11 ומעלה ו-Chrome for Testing.

---

## 3. תמלול ישיבות — התקנה נוספת

התמלול רץ **מקומית במחשב שלך**: האודיו אינו יוצא החוצה. לכן הוא דורש
חבילות נוספות ושני מודלים (~34MB) שאינם חלק מהתוסף.

```powershell
powershell -ExecutionPolicy Bypass -File installer\install_transcription.ps1
```

ההתקנה כבדה (~250MB של חבילות Python) ואורכת כמה דקות. בסיומה הסקריפט שואל את
ה-Daemon עצמו ומדפיס אם `transcribe` ו-`diarize` במצב `ready` — ואם לא, מה
בדיוק חסר.

> אם ה-Daemon כבר רץ לפני ההתקנה — סגור והפעל אותו מחדש (קיצור הדרך
> "ARAD Bulk Daemon") והרץ את הסקריפט שוב כדי לאמת.

**מה התמלול עושה, ומה הוא לא עושה:** הפרדת הדוברים פועלת **בתוך ישיבה אחת
בלבד**. לא נשמרת טביעת-קול, לא נבנה מאגר דוברים, וקובץ האודיו נמחק כשהתמליל
מאושר.

## 4. תקלות נפוצות

| מה רואים | מה לעשות |
|---|---|
| הכרטיס במגדל אומר שהתוסף לא מותקן, למרות שהתקנת | `Ctrl+Shift+R` בלשונית מגדל. התוסף מזריק את עצמו בטעינת הדף. |
| התוסף נעלם אחרי אתחול | התיקייה שחילצת אליה נמחקה או הועברה. חלץ מחדש לתיקייה קבועה וטען שוב. |
| מודול מופיע אפור | הוא לא נרכש לארגון שלך, או שה-Daemon לא רץ (עבור מודולים שתלויים בו). |
| "missing python module" למרות ש-pip הצליח | החבילות הותקנו לגרסת Python אחרת מזו שה-Daemon רץ עליה. הרץ את `install_transcription.ps1` — הוא בוחר את אותה גרסה שה-Daemon משתמש בה. |
| התמלול נכשל על כל קובץ | גרסת PyAV חדשה מדי. `install_transcription.ps1` מתקין מתוך `requirements.txt` שמקבע `av==18.1.0`. |

---

## 5. הסרה

```powershell
powershell -ExecutionPolicy Bypass -File installer\uninstall.ps1
```

ולהסרת התוסף עצמו: `chrome://extensions` ← **Remove**, ומחיקת התיקייה.
